# Partner evidence

ApprovalBridge was built for [neatHack](https://neatlogs.com/hackathon). The app demo uses fictional records and scripted offline responses; it does not establish live model accuracy.

- **neatlogs:** [sanitized recovery record](neatlogs-evidence.json) from a historical live run: a rejected six-document read was corrected to four. Saved write acknowledgements exist. This local summary is not a raw trace export or independently verified project readback, and it does not demonstrate a controlled improvement in model quality.
- **Entire:** [native code-only graph excerpt](entire-graph.ndjson) and [provenance](entire-provenance.json), with 23 symbols, 41 relationships and nine CALLS. It is a retrospective source map, not proof of development chronology or runtime correctness. Private conversations, prompts and checkpoint histories are excluded.
- **cfo.ai:** separate hypothetical pricing, costs, revenue and runway planning. There is no runtime integration. Private plan figures and account details are excluded from this repository.
